# power-tile

**THIS WAS 90% BUILT BY AI, IF THAT BOTHERS YOU THEN MOVE ON**

Power tile is the tiling window manager for those poor souls that are stuck on a corporate windows machine for their day to day tasks.

It features the basics:

* Tiling
* Configurable keybinds for navigation and quick app launching
* A Fuzzy Finder for Applications because the start menu, after all these years, is still hot garbage
* A dedicated status bar that shows your environments, the applications open there, the date/time and your battery percentage
* Hide's the bottom bar and start menu completely
* Basic theming

## Running power-tile
```
git clone https://github.com/easton57/power-tile.git
./power-tile/TilingWM.ps1
```
